Mise — Red brand vs Blue-flame brand

The brand red (--flame, hue 30.4°) and the error red (--flame-deep, same hue) are the same colour — so brand-action and failure are indistinguishable. Char/near-black error was tried and rejected. This pivots the brand to a gas-flame blue (the cyan-edged ring of a lit service-line burner — blue is the hottest flame), which frees red for error. Same content, same neutrals, same token names — only the accent family and error value change. Each column shows the happy-path card, the error state, and the Fire button states so the brand/error collision (left) vs separation (right) is visible.

The resolution. Blue Fire button + blue ✶ on the error card, red stamp + red callout = the eye instantly parts brand-action (blue) from failure (red). The blue is a specific cobalt-cyan (hue 238°, drifting to 232° cyan at the hot bright edge) — a lit burner's flame ring, deliberately not the indigo-purple SaaS-blue cluster (Linear/Stripe/Tailwind ~255–280°). Authentic to the brief: pro service-line burners run blue because blue is the hottest flame. "Fire"/"Fired" still holds — gas flame is fire. Logo is monochrome, so the accent recolour never touches the mark — a cheap pivot.
